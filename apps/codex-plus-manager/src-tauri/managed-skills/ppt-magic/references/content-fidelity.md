# Content Fidelity

Use this reference whenever page copy has been confirmed from a source document.

## Rule

Visible slide text must come from the confirmed page copy.

Do not:

- rewrite titles
- paraphrase subtitles
- summarize body copy into model-authored wording
- add style labels, option labels, or explanatory labels on the slide
- invent slogans, section names, or captions
- change numbers, punctuation, names, dates, or units

Allowed without user approval:

- line breaks
- text box splitting
- font, size, color, weight, and placement changes
- moving text between equivalent visual regions

Allowed only with explicit user approval:

- deleting secondary text
- shortening a phrase
- changing tone
- translating content
- combining or separating source bullets in a way that changes wording

## Variant Rule

When generating multiple style options, keep the same confirmed text across every variant. Distinguish options by filename or external explanation, never by adding visible labels inside the slide.

## Check

Before delivery, compare visible slide text against the confirmed source baseline. Any unapproved addition or wording drift is a blocking failure.
